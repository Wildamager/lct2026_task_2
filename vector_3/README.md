# Вектор 3: прямое чтение внешней Flash-памяти

Подробный отчёт: [report.md](report.md).

**Статус: гипотеза, практическая проверка не проводилась.**

## Предполагаемый сценарий

Подключить внешний программатор непосредственно к микросхеме Flash или выпаять ее и подключить, считать содержимое памяти.

## Причина отсутствия проверки

Для проверки требуются дополнительное оборудование и физический доступ к выводам/площадкам микросхемы. В репозитории есть дамп, полученный через BOOTSEL, но он не подтверждает прямое чтение внешним программатором.
