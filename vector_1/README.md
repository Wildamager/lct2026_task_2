# Вектор 1: штатный загрузочный механизм BOOTSEL

Подробный отчёт: [report.md](report.md).

**Статус: подтверждён на физическом устройстве.**

## Сценарий

Использовать штатный ROM-загрузчик RP2040 для входа в режим `RPI-RP2` и чтения полного содержимого Flash.

## Условия

- Физический доступ к устройству.
- USB-кабель и компьютер с `picotool`.

## Воспроизведение

1. Удержать BOOT, затем подлючить к компьютеру. Если плата уже подключена, то необходимо одновременно зажать BOOT и RESET.
2. Убедиться, что устройство появилось как `RPI-RP2`.
3. Проверить сведения командой `picotool info -a`.
4. Сохранить память командой `picotool save -a dump.bin`.

## Результат

Получен дамп объёмом 2 МиБ с базовым адресом XIP `0x10000000`. Также была предпринята неудачная попытка загрузить через режим BOOT модифицированную прошивку с отключённой проверкой пароля. В дампе обнаружены данные прошивки CyberSafe; анализ PIN описан в [итоговом отчёте](../report.md).
