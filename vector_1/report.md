# Вектор 1. Доступ через штатный загрузочный механизм BOOTSEL

**Статус: подтверждён на физическом устройстве.**

## 1. Цель

Проверить, позволяет ли штатный ROM-загрузчик RP2040 получить доступ к памяти устройства и извлечь прошивку без использования внешнего программатора.

## 2. Условия и средства

- Исследуемое устройство CyberSafe на модуле Waveshare RP2040-Zero.
- Физический доступ к устройству.
- USB-кабель и компьютер.
- `picotool` для идентификации устройства и сохранения Flash. Версия инструмента в имеющихся записях не указана.

## 3. Методика

1. Перевести устройство в ROM-режим BOOTSEL: удерживать BOOT при подключении USB либо, если устройство уже подключено, удерживать BOOT и нажать RESET.
2. Убедиться, что устройство определилось как `RPI-RP2`.
3. Считать идентификационные сведения командой:

   ```bash
   picotool info -a
   ```

4. Получить образ всей Flash:

   ```bash
   picotool save -a dump.bin
   ```

5. Проверить размер файла и зафиксировать его контрольную сумму.

## 4. Результат

Получен полный бинарный образ Flash размером **2 097 152 байта (2 МиБ)**. База XIP-адресов образа — `0x10000000`. Зафиксированные сведения устройства:

| Параметр | Значение |
|---|---|
| Имя прошивки | `usb_token` |
| Версия прошивки | `0.1` |
| Микроконтроллер | RP2040 rev B2 |
| Размер Flash | 2048K |
| SDK | 2.2.0 |
| Board-ID загрузчика | `RPI-RP2` |

SHA-256 файла `dump.bin`:

```text
4f7a43433c0abc431bde5c87b945d7976e1c7c10571f7b02269c19c750e159ab
```

В последующем статическом анализе дампа обнаружен четырёхзначный PIN `3459` по адресу `0x10005500` (смещение `0x5500`). Это результат анализа дампа, полученного данным вектором.

Дополнительно через режим BOOT была предпринята попытка загрузить модифицированную прошивку, отключающую проверку пароля. Попытка не увенчалась успехом. Точный файл прошивки, команда загрузки и сообщение об ошибке в имеющихся материалах не зафиксированы, поэтому причина неудачи неизвестна. Этот результат не опровергает успешное чтение Flash и сам по себе не доказывает, что загрузка изменённой прошивки невозможна.

## 6. Итог

Штатный загрузочный механизм позволил получить полный дамп прошивки при физическом доступе к устройству. Отдельная попытка загрузить модифицированную прошивку для отключения проверки пароля не увенчалась успехом; причину по доступным материалам установить нельзя.
