# Общий доклад по задаче №2. Получение доступа к прошивке современной компьютерной платы с использованием различных техник ревер-инжиниринга

## Краткий итог

В ходе исследования рассмотрены четыре потенциальных вектора доступа к устройству CyberSafe на базе RP2040. Практически подтверждены два: получение полного дампа Flash через штатный загрузочный механизм BOOTSEL и автоматизированный перебор PIN с помощью Raspberry Pi, имитирующего ввод энкодером. Перебор PIN продолжался около 8 часов и зафиксирован на ускоренном видео.

Прямое чтение внешней Flash-памяти отдельным программатором и подключение по SWD не проводились. Эти направления остаются гипотезами.

> **Итог: 4 вектора рассмотрены, 2 подтверждены на практике.**

## Объект и подход

Объект исследования — устройство CyberSafe на модуле Waveshare RP2040-Zero с микроконтроллером RP2040 и Flash-памятью объёмом 2 МиБ. Для практических проверок использовались физический доступ к устройству, виртуальная машина с `picotool`, Raspberry Pi для автоматизации ввода и камера для наблюдения за интерфейсом.

Статус «подтверждён» присвоен только сценариям, выполненным на физическом устройстве. Непроведённые аппаратные проверки обозначены как гипотезы. Описание методики и свидетельств по каждому сценарию приведено в соответствующем подробном отчёте.

## Основные выводы

1. Через штатный ROM-загрузчик RP2040 удалось получить полный дамп Flash размером 2 МиБ. Это подтверждено файлом дампа и зафиксированными сведениями `picotool`. Также предпринималась неудачная попытка загрузить модифицированную прошивку с отключённой проверкой пароля; детали причины отказа не зафиксированы.
2. Автоматизированный перебор PIN выполнен на устройстве: Raspberry Pi имитировал действия энкодера, камера контролировала интерфейс. По имеющимся данным, перебор занял около 8 часов; [видеозапись доступна на Google Drive](https://drive.google.com/file/d/1nKdqRTAGpSUCG8hbRdTu2GWFtVgMZdNv/view?usp=sharing).
3. Прямое чтение внешней Flash отдельным программатором не проводилось. Полученный через BOOTSEL дамп не считается доказательством этого отдельного вектора.
4. Подключение по SWD не проводилось; проверка требует физического подключения и может повредить устройство.
