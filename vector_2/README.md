# Вектор 2: автоматизированный перебор PIN

Подробный отчёт: [report.md](report.md). В нём размещена внешняя ссылка Google Drive на видеодоказательство; сам видеофайл в репозиторий добавлять не требуется.

**Статус: подтверждён на физическом устройстве.**

## Сценарий

Raspberry Pi автоматически имитирует вращение и нажатия энкодера CyberSafe. Камера контролирует светодиодный интерфейс и фиксирует результат ввода.

## Условия

- Физическое устройство CyberSafe.
- Raspberry Pi, подключённый к стенду имитации ввода энкодером.
- Камера для наблюдения за индикацией.


## Воспроизведение

1. Разместить устройство и камеру так, чтобы была видна индикация.
2. Подключить Raspberry Pi к стенду управления энкодером.
3. Запустить автоматизированную последовательность ввода PIN.
4. Зафиксировать успешную индикацию и остановку перебора.

## Результат

Перебор выполнен на устройстве и записан на видео. Статический анализ дампа указывает PIN `3459`; Для перебора потребовалось ~8 ч.
